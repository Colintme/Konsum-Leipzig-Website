# Konsum Leipzig Website

Redesign-Konzept für die Altenburger Filiale von Konsum Leipzig eG. Statische Single-Page-Website (HTML/CSS/JS, kein Build-Schritt nötig).

Öffnen: `index.html` im Browser laden, oder z. B. mit GitHub Pages hosten.

Demo-Projekt — Adressen, Preise und einzelne Kontaktdaten sind zu Übungszwecken angepasst.
